# Существование и гиперболичность неподвижной точки ренормализации удвоения периода при нецелом показателе критической точки

**Yevhen Borzenkov** · ORCID [0009-0002-7946-589X](https://orcid.org/0009-0002-7946-589X)
Депонировано на Zenodo, DOI [10.5281/zenodo.22306911](https://doi.org/10.5281/zenodo.22306911) (05.09.2026). Не рецензировано.
English version — [README.md](README.md).

Компьютерное доказательство на строгой интервальной арифметике: при **каждом** показателе ℓ ∈ [2, 4] — а не только
при чётных целых — оператор ренормализации удвоения периода имеет неподвижную точку, и она гиперболична
с одномерным неустойчивым направлением.

## Теоремы

Для каждого ℓ ∈ [2, 4], в пространстве аналитических функций на явном круге:

- **A (существование).** Уравнение Фейгенбаума–Цвитановича имеет решение G*(ℓ), G*(0) = 1, в шаре радиуса
  8.49·10⁻¹³ вокруг явного центра; оно единственно в пределах 1.75·10⁻⁷ на срезе нормировки. 46 боксов, Ньютон–Канторович.
- **B (гиперболичность).** Производная ренормализации в G*(ℓ) имеет ровно одно собственное значение вне единичной
  окружности — δ(ℓ), вещественное и простое; остальной спектр строго внутри. 706 боксов, операторная теорема Руше,
  худшее значение приёмки 0.9919 < 1.
- **C (аналитичность).** G*(ℓ) и δ(ℓ) вещественно-аналитичны по ℓ; δ(ℓ) ∈ [4.6747, 7.2854].
- **D (независимость от слоя).** Ненулевой спектр с кратностями не зависит от выбора слоя пространства функций в
  явно сертифицированном семействе.

Контроль: δ(4) совпадает с квартикой Burbanks–Osbaldestin–Thurlby до 6.68·10⁻¹⁵. Прежние результаты
(Горбовицкис–Ямпольский; Круз–Смания) — окрестности чётных целых неуказанной ширины; здесь покрытие явное,
равномерное, с ℓ = 5/2 и ℓ = 3 внутри.

## Как воспроизвести

Python 3.13, `python-flint` 0.9.0 (FLINT 3.6.0), `numpy`, `scipy`, `mpmath` 1.3.0. Распаковать три архива из `zenodo/`
рядом с файлами `.md` и выполнить `python _manifest.py verify`: 960 файлов совпадают, пять файлов уровня депозита
(архивы, лицензии) отмечаются как лишние. Дальше — `zenodo/02-REPRODUCE.md`. Быстрые проверки из `04-CODE/`:
`tube_accept.py`, `tests/_tau_test.py`, `tests/_numbers_check.py` — на этом издании (15.11.2026) все проходят.
